# Heist: Key → Home

## فكرة اللعبة
- لاعب يبدأ من Start
- يلتقط Key (مفتاح)
- يصل إلى Home للفوز (حسب إعدادات المستوى: المفتاح مطلوب أو لا)
- Walls تمنع الحركة
- Guards يتحركون على مسارات ويكشفون اللاعب

## شاشات المشروع
- Levels/Menu + Leaderboard
- Play

## فصل Frontend / Backend
- Frontend: عرض الشبكة، إدخال المستخدم، إرسال طلبات للسيرفر، عرض النتائج
- Backend: منطق اللعبة بالكامل (حركة/حراس/فوز-خسارة/حساب score) + قاعدة البيانات

## قاعدة البيانات (SQLite)
- تخزين النتائج (score/ticks/time) + Leaderboard
